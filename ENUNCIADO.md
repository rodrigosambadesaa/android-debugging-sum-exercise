# Enunciado original — Corrección de errores

Práctica de **Desarrollo de Interfaces** cuyo proyecto inicial contiene varios fallos deliberados.

El objetivo es depurar la aplicación hasta conseguir que:

- lea dos valores enteros introducidos por el usuario;
- calcule correctamente su suma;
- trate una segunda caja vacía como valor `0`;
- actualice y muestre el resultado sin cierres inesperados.

La solución moderna añade además validación explícita para entradas no numéricas y desbordamiento y conserva en la documentación la secuencia de errores original para que el repositorio siga siendo útil como ejercicio de depuración.

No existe una base de datos asociada.
